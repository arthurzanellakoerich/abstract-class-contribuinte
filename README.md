Classes Abstratas — Contribuinte 🧾
Exercício desenvolvido para praticar o uso de classes abstratas e herança em Java.

📖 Sobre o projeto
Simulação de um sistema de cálculo de impostos para contribuintes, onde cada tipo de contribuinte tem sua própria regra de tributação.

🧠 O que pratiquei

Classe abstrata — Contribuinte define a estrutura base
Herança — PessoaJuridica estende Contribuinte
Método abstrato — tax() obriga cada subclasse a implementar sua própria regra de imposto
Polimorfismo — cada tipo de contribuinte calcula o imposto de forma diferente
Uso da anotação @Override.
